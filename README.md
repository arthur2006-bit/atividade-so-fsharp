# Atividade de Threads em F#

Implementação dos três exemplos de threads em F#.

## Como executar

Entre na pasta do programa:

```bash
cd Thread1
```

Crie a imagem:

```bash
docker build -t thread1 .
```

Execute:

```bash
docker run --rm thread1
```

Para `Thread2` e `Thread3`, faça o mesmo, alterando o nome da pasta e da imagem.

Exemplo:

```bash
cd Thread2
docker build -t thread2 .
docker run --rm thread2
```

```bash
cd Thread3
docker build -t thread3 .
docker run --rm thread3
```
